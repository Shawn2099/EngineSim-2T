- GT-SUITE theory manual (Gamma Technologies) — free PDF on request; explains 1D gas dynamics.
- Ricardo WAVE theory manual — free PDF.
- SAE Mobilus abstracts — free; full papers ~$30 each. Search: "two-stroke scavenging", "loop scavenging", "port timing".
- MathWorks File Exchange — search "two stroke engine", "IC engine simscape" (community models).
- MathWorks Help: "Modeling an Engine in Simscape", "SI Engine Dynamometer Reference Application".

Program structure (as printed)
  1.  Read the 21x41 UFLO data bank from file "UFLO".
  2.  Menu 50: new data (N) or filed data (F, *.BOX file).
  3.  Nine Y/N-gated data blocks (ENGINEDAT, EXPORTDAT, TRPORTDAT, INPORTDAT,
      EXLENDAT, EXDIADAT, TRPIPDAT, INPIPDAT, COMBDAT).
  4.  DATASET: echo every data value to the screen for checking.
  5.  PORTSTART: derive port heights, areas, equivalent diameters and the
      scavenging-model constants.
  6.  Compute port timing -> piston heights, pipe meshes (NINT), areas (AREA).
  7.  Time-step the whole engine for CYCLESTOP = 9 cycles, calling
      PIPE/PORT/SHOK/OUTFLOW/INFLOW/BOX/CYLINDER each step, drawing to screen.
  8.  Menu 500: R (recalculate), P (printer output), F (file the data), Q (quit).

NOTE A1 (src 26948): printed as "PCl=TCR*PA/2".  Prog.5.1 has the identical
   statement as "PC1=TCR*PA/2.5" (src 26135).  Transcribed here as /2.5 on the
   strength of that parallel; the initial cylinder pressure is thus 2.5 x TCR
   x Patm.  Treated as an OCR loss of ".5", not as a code difference.
NOTE A2 (src 27005): printed "DZ=.9*DZ"; Prog.5.1 has "DZ=.99*DZ" (src 26185).
   Transcribed as .99.  A 0.9 factor would shrink the time step by 10% every
   step, which is unstable by construction, so .99 is taken as correct.
NOTE A3 (src 27018): CYCTRIP is never assigned anywhere in Prog.5.2, so this
   line is dead code (CYCTRIP defaults to 0 and CYC starts at 1).  The same
   construct appears in Prog.5.1 (src 26199) and in Prog.2.x, where CYCTRIP is
   an operator-entered "inspection cycle" (src 20433).  Left as printed.
NOTE A4 (src 27029-27042): the first block of PORT/SHOK calls handles the
   exhaust pipe end (K6), the inlet pipe end (KI) and the transfer pipe end
   (KT).  The transfer-pipe end discharges into the CRANKCASE at PCC1, hence
   "CALL PORT(BT(KT),AT(KT),PCC1,AK)".
NOTE A5 (src 27050): "CALL CYLINDER(PC1,PC2,TC1,TC2,VC1,VC2,MC1,MC2,CYWORK)"
   passes nine arguments to a SUB declared with eight formal parameters
   (SUB CYLINDER(P1,P2,T1,T2,V1,V2,MC,WORK), src 28136).  Printed as in the
   book, and identically in Prog.5.1 (src 26249).  Left unfixed.

SUB STAB(A(),B(),K,S,E) STATIC
SHARED DZ,DTM,DC,RPM
C=60*S/(RPM*E)

NEXT J

END SUB
SUB SETS(A(),B(),K) STATIC

B(J)=1

END SUB
SUB AREA(DA,DB,KA,KB,DF(),F()) STATIC
C=(DB-DA)/(KB-KA)
FOR J=KA TO KB
A=J-KA
F(J)=((DA+C*A)^2)*.7854
NEXT J
KC=KB-1

DF(J)=F(J+1)-F(J)
NEXT J
END SUB

SUB SHOK(A(),B(),KA,KB) STATIC
FOR J=KA TO KB
R1=5*ABS(A(J)-B(J))/(A(J)+B(J))
IF R1<1 THEN GOTO 56

SUB PORT(A,B,P,AK) STATIC
SHARED ABX(),BX(),AKA(),PA
X1=(P/PA)^(1/7)
BX1=B/X1
IF AK>.95 THEN AK=.95
IF BX1<.6 THEN BX1=.6
I=INT(AK/.05)+1
J=INT((BX1-.6)/.02)+1

AB2=RA*(ABX(I+1,J)-ABX(I,J))+ABX(I,J)
RB=(BX1-BX(J))/(BX(J+1)-BX(J))
ABX1=RB*(AB1-AB2)+AB2

END SUB

SUB OUTFLOW(A,B,F,TR,H,C,M,D,CD) STATIC
SHARED GK,GE,PA
CP=481.17*TR^0.25
GAM=1.7847/(TR^0.417)
AB=(A+B)/2
TREF=TR/AB^2
REM TR IS REGARDED AS THE SUPERPOSITION TEMPERATURE
SD=SQR(GAM*GK*TREF)
C=SD*(A-B)/(GAM-1)
H=CP*TR
D=AB^.5*PA/(GK*TREF)
M=CD*C*F*D
MN=C/SQR(GAM*GK*TR)
P1=(.5*(A+1))^7
P2=(.5*(B+1))^7
END SUB
SUB INFLOW(A,B,F,TR,H,C,M,D,CD) STATIC

SUB BOX(PB1,PB2,TB1,TB2,VB1,VB2,MB1,MB2,MIN,MO,CIN,CO,HIN,HO,WORK) STATIC
SHARED CCV,DTM,GK,GE
CV1=269.49*TB1^0.1667
DMI=MIN*DTM
DME=MO*DTM
MB2=MB1+DMI-DME
EIN=DMI*(HIN+.5*CIN*CIN)
EO=DME*(HO+.5*CO*CO)
DW=PB1*(VB2-VB1)

CV2=269.49*TB2^0.1667
TB2=(EIN-EO+CV1*MB1*TB1-DW)/(CV2*MB2)
PB2=MB2*GK*TB2/VB2
WORK=(PB1+PB2)*(VB2-VB1)/2
PB1=PB2
TB1=TB2
MB1=MB2
VB1=VB2
END SUB
SUB BELMOUTH(B,A,PA) STATIC

END SUB
SUB PISTPOS(S,R,C,D,HT,HB) STATIC
SHARED DTOR
A=D*DTOR

END SUB
SUB PAREA(NP,WP,HP,RT,RB,FP,DP) STATIC
SHARED PI

DP=SQR(4*FP/PI)
END SUB
